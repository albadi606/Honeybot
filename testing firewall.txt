curl with spoofed IP header

this is a cmd attack 
 Those are curl commands — command-line HTTP requests. Think of curl as a browser that doesn't render HTML, just sends raw HTTP.

  First command — single attack:                                                                                                                               curl -X POST http://127.0.0.1:8000/login/
  Sends a POST to the login page (same as submitting the login form)                                                                                         
  -H "X-Forwarded-For: 203.0.113.45"
  Adds a fake "I'm coming from this IP" header

  --data "username=admin' OR 1=1 --&password=x"
  Submits SQL injection as the username field

  Result → honeypot logs it as 203.0.113.45 doing SQL injection → auto-blocked.

  Second command — flood test:
  for i in $(seq 1 70)
  Loops 70 times

  Sends 70 rapid requests from fake IP 198.51.100.77 → rate limiter kicks in at 60 req/10s → that IP gets blocked for 15 min.



  # Single shot — spoofed IP 203.0.113.45
  curl -X POST http://127.0.0.1:8000/login/ \
    -H "X-Forwarded-For: 203.0.113.45" \
    -H "X-Real-IP: 203.0.113.45" \
    --data "username=admin' OR 1=1 --&password=x"

  # Flood test — triggers rate limiter (60 req/10s threshold)
  for i in $(seq 1 70); do
    curl -s -X POST http://127.0.0.1:8000/login/ \
      -H "X-Forwarded-For: 198.51.100.77" \
      --data "username=test&password=test" > /dev/null
  done
